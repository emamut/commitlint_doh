About

Commitlint_D'oh! is an open source git commit message editor intended to help you privately write compliant conventional messages without changes to your development environment. It can be used online (not private), or downloaded for private offline use.

Download zip file
Usage

Complete the form with
<type>
<scope>
and <subject>
of your commit. Messages will hint how to comply with the conventional guideline. The "Copy to Clipboard" button is enabled when the first line of the commit message passes the regex linter, click the copy button then paste into your git client.

Benefits
  • Offline privacy
  • Message hints while editing
  • Reduced typing
  • Language/project agnostic
  • Prescribed formatting
  • Free
